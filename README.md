# Sun Prairie West HS Swim & Dive Homepage
A central landing page for the SPWHS Swim & Dive program (boys and girls). This page is simply a redirection hub to making resources on Google Sites more easily accessibly for parents, athletes, and coaches

## Goals
- Improve SEO, making an easy access point for anyone searching for the team on Google
- Link to the Girls Booster Club Page and Boys Booster Club Page
- Not becoming primary resource host; avoiding content duplication

## Future Ideas
- General Links to Social Media, Results, and Photos
- Roster Photos or links to articles

## Additional Notes
- This website will never become the "Main" site to ensure families can easily access information and allow for coach delegation.
